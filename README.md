# 毅见倾新 · The Beginning of Us

Version 1 cinematic event landing page using Next.js, GSAP, ScrollTrigger and Lenis.

## Run
npm install
npm run dev

## Vercel
Push the folder to GitHub and import it into Vercel. No environment variables are required for V1.

Replace the registration section in `app/page.tsx` with your Google Form / registration URL when ready.
